# ArLen — натяжные потолки

Лендинг по брифу и прайсу клиента. Заявки: Cloudflare Worker lead-relay, ref `XTDUDL53MV`.

Контакты, адрес, график и прайс обновлены по правкам клиента. Логотип взят с Яндекс.Диска клиента (img/logo.jpg). Координаты карты найдены по адресу Привольная ул., 2к5 через OpenStreetMap. Ссылка WhatsApp ведёт на номер из правок, подтверждение у клиента не запрашивали.

Калькулятор считает по прайсу клиента; допущение: цена за м² включает монтаж.
